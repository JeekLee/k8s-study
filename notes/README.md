# 실습 기록

겪은 문제와 해결 과정을 남긴다. **실패한 시도도 지우지 않는다** — CKA Troubleshooting(배점 30%)은 결국 이 기록의 양에 비례한다.

## 구조

```
notes/
├── YYYY-MM-DD-주제.md      그날 겪은 문제 하나 (사건 기록)
└── <영역>/                  반복해서 찾아볼 참고 자료
    ├── README.md            해당 영역의 절차와 인덱스
    └── <분류>/
        └── NN_주제.md       번호는 실제 사용 순서를 뜻한다
```

| 영역 | 내용 |
|---|---|
| [`network/`](network/) | 노드 간 통신 · 진단 명령 |
